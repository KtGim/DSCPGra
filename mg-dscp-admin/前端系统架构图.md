## 3. 登录与动态路由流程(时序图)

```mermaid
sequenceDiagram
    participant U as 用户
    participant P as permission.js守卫
    participant S as Vuex store
    participant A as api层
    participant R as Router

    U->>P: 访问任意页面
    alt 无 token
        P->>U: 重定向 /login?redirect=...
    else 有 token 且 roles 已加载
        P->>R: next() 放行
    else 有 token 且 roles 为空
        P->>S: dispatch GetInfo
        S->>A: /getInfo
        A-->>S: 返回 userInfo/roles/permissions
        S->>S: SET_ROLES(默认 ROLE_DEFAULT) / 归一化 *:*:*
        P->>S: dispatch GenerateRoutes
        S->>A: /getRouters 获取动态菜单
        A-->>S: 菜单树
        S->>S: filterAsyncRouter 转换<br/>(Layout/ParentView/loadView懒加载)
        S-->>P: routes = constantRoutes + 动态路由
        P->>R: router.addRoutes(accessRoutes)
        P->>R: next({...to, replace:true}) 重进目标页
    end
```

## 4. 请求链路与错误处理(时序图)

```mermaid
sequenceDiagram
    participant V as 页面(views)
    participant Api as api模块
    participant Req as request.js
    participant S as store
    participant B as 后端

    V->>Api: 调用接口函数
    Api->>Req: service(config)
    Req->>Req: 请求拦截<br/>① isCancelToken 重复请求取消<br/>② token 注入 headers['token']<br/>③ GET 参数序列化
    Req->>B: HTTP 请求(180s 超时)
    B-->>Req: 响应
    alt responseType=blob
        Req->>Req: parseBlobError 解析 JSON 错误兜底
    end
    Req->>Req: 业务码分流 handleBusinessCode
    alt code=200
        Req-->>V: 返回 res.data
    else code=401
        Req->>S: FedLogOut(清token) + isRelogin 防重入
        Req->>V: 弹窗"重新登录" → 跳 /admin
    else code=500
        Req->>V: Message 错误提示
    else 其他非200
        Req->>V: Notification.error(后端 msg)
    end
```

## 11. 架构特点与风险

**特点**
- 若依(RuoYi)风格二次开发:动态路由 + 后端菜单 + 三级权限体系
- 页面主流范式:`SearchTable`(CustomForm + CustomTable 组合),大量配置化开发
- 请求层扩展点丰富:重复请求取消(`isCancelToken`)、延迟返回(`delayResponse`)、blob 错误兜底
- 大数据场景:批量请求器(Web Worker 并发)、虚拟滚动表格、async 分页总数

**风险点**
1. `utils/ossAli.js` 与 `.env` 中 OSS AK/SK 明文,前端直传无 STS 签名
2. 无 token 自动刷新机制,401 仅弹窗引导重新登录
3. `permission.js`、`request.js` 共享模块级 `isRelogin` 全局标志,存在耦合
4. 动态路由组件路径与 `src/views` 文件必须严格匹配,否则导航失败
5. 报价(`cudQuotationNew.vue`)等单组件连接数过高,复杂度过大
6. 图谱构建时间早于当前代码(commit `4454997d`),精确结论以当前源码为准
